# Regol 0.4.0

The CLI now supports `regol live FILE.gol` through the separately installed `regol-live` executable. It forwards the server arguments and exit status. Install both commands with `cargo install --locked regol-cli regol-live`.

The shared Overpass executor accepts GOQL filters on stored sets and can report per-set candidate and match counts. Regol Live uses these features in its query workspace.

Applications using the Rust libraries can update their `regol` and `regol-overpass` dependencies together to `0.4`. The map server is available from the separate `regol-live` crate. [Regol Live](https://github.com/regol-gis/regol-live)
