regol reads GeoDesk GOL 2.0 files and builds them from OpenStreetMap PBF snapshots in pure Rust.

- Query features with GOQL, inspect tags and geometry, and traverse way nodes and relation members in Rust. The reader supports paged I/O, bounded caches, immutable memory maps, parallel queries, and HTTP/3 or pooled HTTP/1.1 byte-range reads.
- Combine queries with set intersection, union and difference, follow shared vertices and relation roles, and filter by exact geometry or distance. Measure feature length, perimeter, area, centroid and distance with typed SI units (`uom`).
- Use `regol build` (or the library's `build` feature) to compile raw or zlib-compressed `.osm.pbf` snapshots into GOL 2.0 files using the pure-Rust multi-threaded builder, with automatic disk spill for large inputs and configurable tile/R-tree layout presets.
- Use `regol query` on local files or HTTP(S) URLs for counts, IDs, OSM XML and PBF, or GIS exports in GeoJSON, GeoJSONL, WKT and CSV. Limit results with a bounding box or a GeoJSON polygon.
- Use `regol info` to inspect library metadata and `regol check` to verify the active snapshot's checksums, tiles and feature records.

The release includes the Linux x86-64 `regol` binary archive (with dependency notices), both Cargo source packages (`regol` and `regol-cli`), and `SHA256SUMS`. Requires Rust 1.85 or later (building the CLI or `http` feature on Linux also requires OpenSSL development headers and `pkg-config`).
