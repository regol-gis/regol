regol 0.2.2 recovers the single-threaded query iteration and tag-reading regressions introduced in 0.2.1 while preserving 0.2.1's CLI export speedups, fast build times, and smaller binaries.

- **Unbounded query scan specialization**: Split `PreparedQuery` scanning into dedicated concrete entry points (`next_unbounded` for `StreamPlan::Other` iterators and `scan_unbounded_erased` for `try_fold`, `try_fold_in_bounds`, `SpatialFilter`, and single-threaded `QueryExecutor` fallbacks), eliminating per-record indirect calls on `|| Ok(true)` inside tight leaf traversal loops while keeping `scan_in_erased` for budgeted parallel leases.
- **Inlined tag iterator construction**: Marked `Feature::tags` and `Tags::new` `#[inline]` so tag-scanning hot loops avoid out-of-line `Tags` construction across codegen units.

The release includes the Linux x86-64 `regol` binary archive (with dependency notices), both Cargo source packages (`regol` and `regol-cli`), and `SHA256SUMS`. Requires Rust 1.85 or later (building the CLI or `http` feature on Linux also requires OpenSSL development headers and `pkg-config`).
