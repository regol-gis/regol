## Overpass QL

The new `regol-overpass` crate compiles and executes the bounded Overpass QL subset used by Regol Live. Native and WebAssembly applications can read ordered groups of feature handles or counts. Each `out` statement produces its own group.

The CLI runs the same queries against a local GOL or an HTTP range source. This example counts café nodes in a viewport supplied on the command line.

```sh
printf '%s\n' 'node[amenity=cafe]({{bbox}}); out count;' |
  regol overpass region.gol --file - --bbox=-0.14,51.49,-0.10,51.52
```

Use `-f ids`, `-f count` or `-f geojson` for newline-delimited JSON output. For named areas in an HTTP source, supply a matching local index with `--area-index`. Existing GOQL commands continue to use `regol query`. [CLI examples](https://github.com/regol-gis/regol/blob/v0.3.0/cli/README.md#overpass-ql)

## Upgrading from 0.2.2

- The minimum Rust version is now 1.90. Linux source builds of the CLI or the library's `http` feature require OpenSSL development headers and `pkg-config`.
- GeoJSON and GeoJSONL exports now write OSM tag values as strings. Add `--typed-tags` to `regol query` if your application expects numeric tag values as JSON numbers.
- The optional `gob` feature imports tiles from GOB 2.0 snapshots. `GobCatalog` and `GobStore` support selecting tiles for a viewport, querying loaded tiles and writing them to a GOL. [Import example](https://github.com/regol-gis/regol/blob/v0.3.0/examples/import_gob.rs)
- The query API adds `Predicate::present` for tag-key presence and `PreparedQuery::candidates_in_bounds_with_min_width` for pruning narrow R-tree branches. Linux mmap scans now adapt read-ahead to observed page faults.

The GitHub release includes the Linux x86-64 GNU binary, source archives for all three crates, and `SHA256SUMS`. [Full changes since 0.2.2](https://github.com/regol-gis/regol/compare/v0.2.2...v0.3.0)
