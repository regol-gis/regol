regol 0.2.1 accelerates CLI export serialization, adds partition-parallel unordered streaming, and significantly reduces Rust compile times and binary size.

- **Faster CLI exports**: Added an exact-verified fast inverse Mercator projection, single-pass polygon ring projection, direct byte-buffer formatting (with fast precision-7 decimal and JSON escaping paths), zero-allocation simple node/way decoding, scoped-worker parallel text encoding with recycled buffers, parallel CSV export, and parallel chunk formatting for sorted OSM XML export.
- **Unordered partition-parallel streaming by default**: Multi-threaded `regol query` exports for GeoJSON, GeoJSONL, WKT, CSV, and IDs now stream partitions in parallel by default (matching `--unordered`). Pass `--ordered` to preserve deterministic tile/R-tree traversal order, or `--unordered` explicitly.
- **Library query and parallel execution improvements**: Cached tile/dictionary state in `Tags` with an inline local-tag fast path, added sorted key-code lookup in `Feature::tag`, added contiguous-slice varint decoding in `WayNodes`, balanced R-tree expansion in `Features::partitions`, and added `QueryExecutor::try_fold_reduce_once`.
- **Faster builds and smaller binaries**: Reduced monomorphization bloat across query scanning and CLI export paths, cutting release/test compile times and shrinking the `regol` release binary without affecting runtime performance.

The release includes the Linux x86-64 `regol` binary archive (with dependency notices), both Cargo source packages (`regol` and `regol-cli`), and `SHA256SUMS`. Requires Rust 1.85 or later (building the CLI or `http` feature on Linux also requires OpenSSL development headers and `pkg-config`).
