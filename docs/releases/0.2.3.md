## Upgrading from 0.2.2

- **GeoJSON and GeoJSONL exports now write OSM tag values as strings.** For example, a height stored numerically now appears as `"height":"3.25"`. If your application expects JSON numbers, add `--typed-tags` to `regol query` to restore the 0.2.2 behavior. Geometry coordinates remain numeric in both modes.
- **Building the library or CLI now requires Rust 1.90 or later**, up from 1.85. The prebuilt Linux x86-64 binary can be used without installing Rust.

## Library and query changes

- The optional `gob` feature imports tiles from GOB 2.0 snapshots. Use `GobCatalog` to select tiles for a viewport, load them into a `GobStore`, and query them or write them to a GOL. If a query needs an unloaded tile, `Error::MissingTile` identifies which tile to fetch before retrying. The importer supports complete tile payloads only. [Import example](https://github.com/regol-gis/regol/blob/v0.2.3/examples/import_gob.rs)
- `Predicate::present` matches a tag key with any stored value, including `no` and the empty string. For spatial queries, `PreparedQuery::candidates_in_bounds_with_min_width` can skip R-tree branches too narrow to contain a feature of interest. Apply the final width test to each returned candidate.
- On Linux, memory-mapped queries now measure the size and wait time of page faults. When the kernel already fetches large ranges and the faults are slow, both serial and parallel scans leave read-ahead to the kernel.

## Builder and release security

- PBF builds now create owner-only spill directories on Unix. If all decoder workers exit, a producer waiting on a full queue wakes up so the build can terminate.
- The workspace updates its direct `rstar` dependency to 0.14, along with `prost`, `sha2`, and `getrandom`. CI now audits both Cargo lockfiles and checks proposed dependency changes for known advisories.
- GitHub releases now use a separate publishing job. Starting with 0.2.3, the published tag and attached files are immutable.

The release includes the Linux x86-64 GNU binary archive with dependency license notices, the `regol` and `regol-cli` source crates, and `SHA256SUMS`. [Full changes since 0.2.2](https://github.com/regol-gis/regol/compare/v0.2.2...v0.2.3)
